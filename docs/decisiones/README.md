# Decisiones (ADR)

Una ficha por decisión que cueste deshacer o que alguien (tú o Claude) podría volver a discutir dentro de tres semanas: stack, base de datos, autenticación, dónde se despliega, qué no se hace…

- Se crean con `/decision` a partir de [`_plantilla.md`](_plantilla.md), numeradas `0001`, `0002`…
- **No se editan después de aceptadas.** Si se cambia de idea, se crea una nueva que *sustituye* a la anterior y se marca la vieja.
- Antes de proponer algo que contradiga una decisión aceptada, Claude debe citarla y preguntar.
