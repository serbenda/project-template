# Fases

Cada bloque de trabajo tiene una ficha `FNN-titulo-corto.md` creada con `/nueva-fase` a partir de [`_plantilla.md`](_plantilla.md).

- Una fase debe caber en **una PR revisable**. Si no cabe, se parte en dos.
- El **plan se aprueba antes** de escribir código.
- La sección **Resultado** se rellena al cerrar (`/cerrar-fase`) y es el historial del proyecto: [STATE.md](../STATE.md) solo resume las últimas.
- Las fases no se borran: las descartadas quedan marcadas como ⛔ con el motivo.
