### Añadido
- Organización del trabajo con agentes ([decisión 0001](docs/decisiones/0001-organizacion-del-trabajo.md)): `docs/VISION.md`, `docs/STATE.md`, `docs/ROADMAP.md` (etapas `E0…`, fases `F01…`), fichas en `docs/fases/`, ADR en `docs/decisiones/`, `docs/RIESGOS.md`, `docs/ARQUITECTURA.md` y `docs/SETUP.md`.
- Comandos `/estado`, `/nueva-fase`, `/cerrar-fase` y `/decision`, y subagente `revisor-arquitectura`. `/preparar-pr` ejecuta `make verify` y los tres revisores.
- `Makefile` con `make dev`, `make test`, `make lint`, `make links` y `make verify` (reproduce la CI en local).
- `.claude/launch.json` para la vista previa, `.vscode/` con extensiones recomendadas y ajustes, y `.env.example`.

- Estructura inicial: Definition of Done, flujo development → main, CI (Gitleaks, formato, HTML, enlaces), CodeQL, Dependabot, publicación en GitHub Pages y script de configuración.
- Skill `security-audit` de Cloudflare en `.claude/skills/`, fijada al commit `c1c8a8c`.
- Skills `web-perf` (Cloudflare, `cbf893b`) y `repo-security-posture` (superagent-ai, `0da315b`).
- Configuración de Claude Code en `.claude/`: sin firma en commits y PRs, permisos deny/ask/allow, hook `guardia.sh` con pruebas, subagentes `revisor-seguridad` y `revisor-dod`, y comando `/preparar-pr`. `CLAUDE.md` importa `AGENTS.md`.
- Las skills pasan de `.agents/skills/` a `.claude/skills/`.
- Hook de git `.githooks/commit-msg` y job **Autoría** en la CI contra firmas de IA y autores incorrectos.
- GitHub Actions fijadas a un SHA y shellcheck en la CI.
- `docs/SEGURIDAD.md` y `docs/claude-settings-global.json`.
- Revisión de seguridad independiente aplicada: el agente no puede modificar `.claude/` ni `.githooks/`, se bloquean `--no-verify`, cambios de remoto, hacer público el repo, `--author`, lecturas de `.env` por cualquier vía y variantes de push a main y la firma "Generated by"; la CI revisa también el committer y las ediciones de la PR; herramientas de lint con versión exacta. 62 pruebas del hook.

### Corregido
- `guardia.sh` fallaba con el bash 3.2 de macOS (`mapfile` no existe y el `sed` de BSD no entiende `\n`): salía con código 1, que Claude Code no trata como bloqueo, así que **no bloqueaba ningún comando de shell en Mac**. Ahora es compatible con bash 3.2 y las pruebas pasan en macOS.
